# 🌱 EcoTrip Calculator

<img width="1360" height="907" alt="image" src="https://github.com/user-attachments/assets/c4aba29b-83d4-4f8e-8f26-a2e32801bbdc" />


Calculadora interativa de impacto ambiental para viagens.
Com base na distância, meio de transporte e perfil do trajeto, o sistema estima a emissão de CO₂ e apresenta equivalentes ambientais e sugestões sustentáveis.

---

## 🚀 Sobre o projeto

O **EcoTrip Calculator** foi desenvolvido com o objetivo de ajudar usuários a entenderem o impacto ambiental de seus deslocamentos e incentivá-los a tomar decisões mais sustentáveis.

---

## ✨ Funcionalidades

* 📍 Entrada de origem e destino
* 📏 Definição de distância (input + slider)
* 🚗 Seleção de meio de transporte
* 🛣️ Perfil do trajeto (urbano, rodovia, misto)
* 📊 Cálculo de emissão de CO₂ em tempo real
* 🌳 Equivalentes ambientais:

  * Árvores necessárias para compensação
  * Quilometragem equivalente de carro
  * Cargas de celular
* 💡 Sugestões inteligentes de transporte sustentável
* 📱 Layout responsivo
* 🎨 Interface moderna estilo aplicação web

---

## ⚙️ Como funciona

O cálculo da emissão é baseado na fórmula:

Emissão = Distância × Fator de emissão × Perfil

* Os fatores de emissão são dados médios (g CO₂/km)
* O resultado final é convertido para **kg de CO₂**
